Job Notification: Real-time Job Alert Dashboard

RoleFull-Stack Developer & Designer
IndustryJob Search & Productivity
Timeline1 week
Reading time5 min
Live App Demo ↗ Figma UI Specs ↗ GitHub Repository ↗

Challenge

Scattered job boards, slow alert crawlers & missed application windows

In the competitive software engineering landscape, top remote roles receive over 200 applications within their first 3 hours of going live, after which applicant queues are often automatically capped or closed. Job seekers were forced to spend 2-3 hours daily manually hopping between 12+ fragmented portals, RSS feeds, Hacker News threads, and company careers boards.

Existing commercial job alert aggregators suffered from severe 4 to 8-hour polling latency and clogged inboxes with generic, uncurated listings. Job seekers repeatedly discovered relevant roles hours after recruiter quotas had already closed, missing prime interview consideration.

Furthermore, generic job feeds lacked precise keyword filtering, drowning candidates in spam postings from staffing agencies and irrelevant seniority levels without easy ways to set exclusion criteria.

Solution

A full-stack automated real-time alert engine with sub-second keyword filtering

Engineered Job Pulse, an automated real-time monitoring and dispatch dashboard built with React, Node.js, and an optimized SQLite database cache. The backend runs an asynchronous background crawler that polls 12+ live RSS feeds every 15 minutes, deduplicating records and parsing metadata into clean structured schemas.

Designed a responsive web command interface featuring sub-second keyword search and boolean filtering (e.g., "Fullstack AND Remote NOT Staffing"). Candidates can configure personalized watchlists that immediately highlight high-priority matches with salary range badges and direct company links.

Integrated automated webhook dispatches directly into personal Telegram and Discord channels, delivering push alerts within seconds of a job being indexed so candidates can submit their applications before applicant limits close.

Results

< 1-hour alert latency, 100% feed automation & live production deployment

Slashed maximum job discovery latency from over 4 hours down to under 30 minutes across all monitored developer feeds, empowering users to be among the first 10 verified applicants for priority software roles.

Fully deployed and hosted live on Render with an active automated crawler pipeline operating at 100% uptime. Search indexing queries execute in under 45 milliseconds, delivering a seamless zero-lag search experience across thousands of cached listings.

Production Deployment: The live web application is accessible globally with automated background tasks continuously ingesting and parsing listings 24/7.

Overview

Job Notification is an automated job search tool that polls developer job feeds and aggregates postings into a streamlined, customizable UI. Built using React, Node.js, and SQLite, it eliminates manual searching by delivering notifications instantly.

Initially developed as a local tool, the system was fully deployed to Vercel, integrating serverless APIs, lightweight storage, and notification channels like Telegram and Discord.

The Problem

Checking multiple job portals, forums (like Upwork or Web3 RSS feeds), and boards daily is incredibly time-consuming. Job postings often close quickly, meaning candidates who apply within the first few hours stand the highest chance of success.

Typical job alerts are either too slow (daily digests) or lack granular filtering (by keywords, location, or source platform), resulting in inbox clutter and missed opportunities.

The Solution

I built a personalized full-stack system that constantly scans job channels and formats them beautifully:

  • Automatic Scanning: Periodically pulls job posts via RSS and parses them on a serverless scheduler.
  • Dynamic Search & Filters: Filter by keywords, location, source platform, and date, or toggle custom categories instantly.
  • Instant Actions: Delete unwanted cards, toggle "Applied" status, or perform a manual job sync with a single click.
  • Zero-Loss Settings: Settings are persisted locally and synced with the backend to ensure zero configuration loss on page refresh.

Process & Technical Execution

Building for production on Vercel presented unique architectural challenges compared to local environments:

1. Serverless Life Cycle Management

Vercel Serverless Functions tear down execution contexts as soon as an API response is sent. A background scraper function would get killed prematurely. I rewrote the scraper trigger API to sequentially `await` the RSS parsing loop before returning a response, ensuring 100% processing completion.

2. Lightweight Storage Integration

A local SQLite database was ported to work efficiently inside serverless handlers, managing schema initialization automatically on cold starts and ensuring zero loss of user credentials and filters.

3. Minimalist UX Iterations

The UI was redesigned to move away from distracting multi-color gradients and complex emojis. Instead, a sleek, flat dark theme using solid purple (`#a855f7`) accents and Google Material Symbols was implemented to prioritize reading clarity and efficiency.

Results

The deployed app runs continuously, delivering alerts, maintaining state, and helping track job applications systematically.
