Phase 1: Empathize

Understanding the Users

To understand why users were abandoning the transfer flow, I conducted qualitative research through 10 user interviews and analyzed app store reviews. I discovered that users felt the app was "too corporate" and "confusing" for everyday tasks.

Primary Persona

"The Busy Professional"

Goals: Wants to split bills and send money in under 10 seconds.

Frustrations: Too many steps to add a new recipient. Confusing navigation.

Secondary Persona

"The Budgeter"

Goals: Needs a clear overview of monthly spending.

Frustrations: Hidden fees and unclear transaction categories.

Key Insight: 80% of users only used 3 core features: Checking balance, sending money, and viewing recent transactions.

Phase 2: Define

Defining the Core Problem

Based on the research, I framed the problem statement:

"Young professionals need a frictionless way to send money and track daily spending without navigating through complex, enterprise-style banking menus."

I mapped out the current user journey and created a new user flow that reduced the steps to send money from 7 clicks down to 3 clicks.

Phase 4: Design

High-Fidelity UI & Design System

I developed a design system that utilized a modern, friendly color palette while maintaining the trust required for a banking app. The UI features large, accessible touch targets and clear typography.

Accessibility Considerations

I ensured all text met WCAG AA contrast standards, added haptic feedback suggestions for buttons, and implemented a dynamic type scale for users with visual impairments.

Phase 5: Validate

Usability Testing & Results

I conducted moderated usability tests with 5 participants using an interactive Figma prototype. Users were asked to complete specific tasks like "Send $20 to Sarah" and "Find out how much you spent on food last week."
